# Student Performance Data Cleaning

## Project Overview

This project explores basic data manipulation and filtering using Python and the Pandas library. The Jupyter Notebook contains exercises involving a student performance dataset, including loading CSV data, filtering records, and updating column values.

## Objectives

- Load CSV datasets into Pandas DataFrames.
- Inspect and filter student records.
- Practise conditional selection using Boolean expressions.
- Update values based on specified conditions.
- Develop foundational data analysis skills.

## Technologies

- Python 3
- Pandas
- Jupyter Notebook

## Getting Started

1. Clone this repository.
2. Install the required Python packages.
3. Open the Jupyter Notebook.
4. Run the cells sequentially.

Install dependencies:

```bash
pip install -r requirements.txt
```

## Topics Practised

- Reading CSV files with `pd.read_csv()`
- DataFrame filtering with conditional expressions
- Selecting rows based on column values
- Updating values with `.loc`
- Inspecting and printing DataFrames
